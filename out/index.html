LinkTap

一个动作，省去绕路。

One action. No detour.

为频繁收集、整理和分享链接而设计，简单到不需要改变习惯。

Made for collecting, organizing, and sharing links without changing how you browse.

01

任意组合

Any combination

自由组合 Control、Option、Shift 和 Command，单键或四键都可以。

Combine Control, Option, Shift, and Command—from one key to all four.

02

精确触发

Exact activation

只在组合完全匹配时复制，避免误触、跳转或意外下载。

Copy only on an exact match, preventing accidental navigation or downloads.

03

本地且私密

Local and private

没有账号、分析或追踪；链接只会写入你自己的剪贴板。

No account, analytics, or tracking. Links go only to your clipboard.

开始使用 Get started

三步安装。

Install in three steps.

  1. 1

    下载并解压

    Download and extract

    下载最新的 LinkTap.zip，然后将它解压。

    Download the latest LinkTap.zip, then extract it.

  2. 2

    打开扩展程序页面

    Open Extensions

    chrome://extensions/

  3. 3

    加载文件夹

    Load the folder

    开启“开发者模式”，点击“加载已解压的扩展程序”。

    Enable Developer mode and select Load unpacked.
